# Verify

Verification is read-only except for disposable test artifacts unless fixes are separately requested.

Define the claims, contracts, and risks to verify. Inspect the implementation rather than trusting test names or prior reports. Start with the smallest falsifying check, then expand to affected tests, supported configurations, boundaries, failure paths, security, performance, or end-to-end behavior in proportion to risk.

Investigate unexpected results. Distinguish product failures from environment and fixture failures. Clean up disposable artifacts.

Report the checks, evidence, failures, remaining gaps, and confidence. Say plainly when no high-confidence issue was found.
