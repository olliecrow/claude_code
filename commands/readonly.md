# Read-only task

Answer the user’s question from evidence without changing files, source, tests, configuration, branches, commits, accounts, services, or other external state.

Read repository instructions first. Inspect the smallest relevant surface, test important hypotheses with non-mutating checks, and distinguish proven facts from inference. If the request would require a change, explain the needed change and stop.

Lead with the answer or blocker. Cite file locations or authoritative sources where useful, and state any material uncertainty.
